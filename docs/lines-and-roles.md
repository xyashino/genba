# Lines, Roles, and Forge Andon

Target repos declare only repo-unique hooks in `.genba/config.json`. Built-in Lines and `ROLE.md` contracts ship inside the `genba` binary via Bun text imports (`with { type: 'text' }`).

## Repo Manifest (`.genba/config.json`)

Auto-generated by `genba init` from stack files, CI config, installed CLIs, and `origin` URL:

```json
{
  "project": "payments-api",
  "git": { "provider": "github" },
  "workspace": { "setup": ["bun install --frozen-lockfile"] },
  "checks": {
    "quick": ["bun run lint"],
    "verify": ["bun run ci:verify"]
  },
  "context": {
    "rules": ["AGENTS.md"],
    "conventions": []
  }
}
```

## Built-in Repo-Agnostic Lines

| Line | Stations | Use Case |
| :--- | :--- | :--- |
| `fast` | `build -> quality-gate -> deliver` | Chores, docs, small fixes |
| `standard` | `build -> quality-gate -> audit -> deliver` | Most bugs and scoped tasks |
| `feature` | `plan -> build -> quality-gate -> audit -> deliver` | Multi-file features |

- `workspace.setup` binds to `config.workspace.setup`; `quality-gate` binds to `config.checks.verify`.
- Retry escalation ladder promotes tiers automatically (`fast -> strong -> top` across configured runners) instead of repeating the same failure.

## Universal `ROLE.md` Contract (`stage: runtime`)

Built-in roles (`planner`, `builder`, `doctor`, `mechanic`) compile through `@repo/prompt` with typed frontmatter enforced live by the Cell when the agent calls `genba operator done`:

```markdown
---
id: builder
stage: runtime
mode: write
input:
  order: string
  checks: string
  rules: string
  feedback: string
  lessons: string
  operatorCommand: string
outputs:
  report: { file: report.md, requiredHeadings: ["Changes", "Checks"] }
  commit: { file: commit.txt, format: conventional }
guards:
  requireDiff: true
  forbidPaths: [".git/**"]
---
```

- **Live gatekeeping**: failed output/guard checks return non-zero to `genba operator done` so the live agent fixes them in-session.
- **Runner quirks stay in adapters**: CLI-specific rules live in `adapters/runners/*.ts`, never in `ROLE.md`. Each adapter maps its CLI to one common API (`buildCommand`, `buildHeadlessCommand`, `parseOutput`).
- **Repo memory**: optional `.genba/lessons/<role>.md` injects recurring repo-specific fixes into context.

## Forge-Native Delivery & Andon (`ForgePort`)

| Outcome | Forge Action (`gh` / `glab`) | Local / Hub Record |
| :--- | :--- | :--- |
| **Delivered** | Push branch, open/update PR/MR with proof + retry table | Save `prUrl`, `prNumber`, telemetry; sync merge outcome later |
| **Escalated (Andon)** | Push WIP branch, open Draft PR/MR + `genba:andon` Issue with Mechanic diagnosis | Save `issueUrl`, `draftPrUrl`; free Cell immediately |
